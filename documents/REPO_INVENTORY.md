## First Cleanup Wave Applied Here

- Canonicalized the mentor monitor surface to `abigail_router::monitor::mentor_chat::*` and removed the deprecated `monitors::*` shim.
- Promoted the trust-paper alignment note into `documents/DECENTRALIZED_TRUST_PAPER_ALIGNMENT.md` and removed the broken README/CLAUDE PDF reference.
- Deleted the dead `abigail/` subtree content that was no longer in the workspace or referenced by docs/tests.
- Deleted the unreferenced `documents/README_ALTERNATIVE.md`.
- Added ignore rules for local build caches, release staging folders, `output/`, and generated bundled binaries in `tauri-app/`.
- Tightened the drawer tests so mount-time async updates settle cleanly instead of emitting React `act(...)` warnings.

## Deferred Sunset Notes

- `tauri-app/src/chat_coordinator.rs` still accepts the deprecated `target` input and normalizes it to `AUTO`. Keep until external callers are audited; remove only after no live caller still sends it.
- `tauri-app/src/commands/orchestration.rs` still depends on deprecated `OrchestrationScheduler`. Keep until Tauri orchestration finishes moving to `abigail_queue`.
- `entity-daemon` and `hive-daemon` keep their ignored integration tests for now. They should be revisited in a dedicated runtime-hardening pass, not deleted blindly.
