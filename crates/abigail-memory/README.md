## Memory Layers

```text
Working (2h)          -> short-term buffer, recent active context
Episodic (30d)        -> conversations, events, lived narrative recall
Semantic (2y)         -> facts, relationships, durable knowledge
Crystallized (forever)-> immutable soul and birth-document-tied updates
```

Retention summary:

- `Working`: prune after 2 hours.
- `Episodic`: prune after 30 days.
- `Semantic`: prune after 2 years.
- `Crystallized`: never prune; treat as immutable.
